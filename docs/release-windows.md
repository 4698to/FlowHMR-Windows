# FlowHMR Windows v0.3.9

在顶栏打开「检查更新」，可查看更新说明并下载安装 v0.3.9。也可手动导入官方便携 ZIP。

- **当前角色 FBX。** 自定义 FBX 保存并应用重定向后，打开「导出动作」会默认选择「当前角色 FBX」。导出保留角色的原骨架和校正后的动作，蒙皮可选。
- **FlowHMR FBX（源动作）。** 导出列表标明「源动作」，此格式用于导出源 SMPL-H 骨架和动作。

可直接打开已有工程重新导出。已在 Blender 4.5.3 回读同一份 478 帧工程的带蒙皮和仅骨架 FBX，两份文件保留原骨架和校正，逐帧骨骼变换一致。
